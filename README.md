# КЭА Дашборд — Инструкция по установке

## Файлы проекта
- `index.html`       — главная страница дашборда
- `manifest.json`    — настройки PWA (иконка, название)
- `APPS_SCRIPT.js`   — код для Google Apps Script (бэкенд)

---

## ШАГ 1 — Настрой Google Apps Script

1. Открой таблицу "КЭА — Мастер задач" в Google Sheets
2. Меню сверху → **Расширения** → **Apps Script**
3. Удали весь код в редакторе
4. Скопируй содержимое файла `APPS_SCRIPT.js` и вставь
5. Нажми 💾 (сохранить)
6. Нажми **Развернуть** → **Новое развёртывание**
7. Тип: **Веб-приложение**
8. Настройки:
   - Описание: `КЭА API v1`
   - Выполнять как: `Я (мой аккаунт)`
   - Доступ: **Все** (Anyone)
9. Нажми **Развернуть** → скопируй URL вида:
   `https://script.google.com/macros/s/XXXXX/exec`
10. Сохрани этот URL!

---

## ШАГ 2 — Вставь URL в дашборд

1. Открой файл `index.html`
2. Найди строку (в самом низу файла):
   ```
   const APPS_SCRIPT_URL = 'ВСТАВЬ_СВОЙ_URL_ЗДЕСЬ';
   ```
3. Замени `ВСТАВЬ_СВОЙ_URL_ЗДЕСЬ` на URL из Шага 1

---

## ШАГ 3 — Загрузи на GitHub Pages

1. Зайди на github.com → создай репозиторий `kea-dashboard`
2. Загрузи файлы: index.html, manifest.json
3. Settings → Pages → Branch: main → Save
4. Через 2-3 минуты сайт будет на:
   `https://[твой_username].github.io/kea-dashboard/`

---

## Проверка
- Открой ссылку — должны загрузиться тестовые задачи
- На телефоне: браузер → "Добавить на экран" → появится иконка КЭА
